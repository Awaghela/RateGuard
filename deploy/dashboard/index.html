    How it works, in 30 seconds
    1. nginx spreads requests across two identical RateGuard servers.
    2. Each server looks up the client's policy (bucket size and refill rate). Policies live in PostgreSQL and are cached for 5 seconds, so the database is off the hot path.
    3. The server runs one Lua script in Redis. Redis runs scripts one at a time, so two servers can never spend the same token. The script refills the bucket for the time that passed, takes a token if there is one, and answers allowed or rejected.
    4. Every decision is counted in Prometheus, which feeds the charts on this page.
